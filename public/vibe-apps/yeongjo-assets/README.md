# 영조 영상/이미지 넣는 곳

이 폴더에 아래 이름으로 파일을 넣으면 게임 화면에 자동으로 나옵니다.
파일이 하나도 없으면 그림(SVG)으로 그린 영조가 대신 나옵니다.

| 파일 이름 | 설명 |
|---|---|
| `idle.mp4` | 가만히 앉아 있는 영상 (눈 깜빡임 정도, 반복 재생) |
| `talk.mp4` | 말하는 영상 (영조 대사가 나오는 동안 반복 재생) |
| `king.jpg` | 영상이 없을 때 쓸 정지 이미지 |

- 영상은 가로로 긴 화면(약 16:7~16:9)이 잘 어울립니다.
- 소리는 쓰지 않으니 영상에 소리가 없어도 됩니다.
- AI 영상 도구(예: 이미지 → 영상 생성)로 "조선 임금이 어좌에 앉아 있는 모습 / 말하는 모습" 두 개를 만들어 넣으면 됩니다.
