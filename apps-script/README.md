# 캐치볼 영상 평가 — 구글 드라이브·시트 연동 설치 안내

학생이 올린 영상을 선생님 구글 드라이브에 저장하고, 제출 목록과 채점 결과를 구글 시트에 기록하려면
앱스크립트(Apps Script)를 선생님 구글 계정으로 한 번만 배포하면 됩니다. 약 10분 걸립니다.

## 1. 앱스크립트 만들기

1. https://script.google.com 에 선생님 구글 계정으로 들어가서 **새 프로젝트**를 누릅니다.
2. 왼쪽 위 "제목 없는 프로젝트"를 눌러 이름을 `캐치볼 평가` 로 바꿉니다.
3. 편집창에 있는 내용을 모두 지우고, 이 폴더의 `Code.gs` 파일 내용을 전부 복사해 붙여넣습니다.
4. 저장(💾 또는 Ctrl+S).

## 2. 선생님 키 정하기

1. 왼쪽 메뉴의 ⚙️ **프로젝트 설정**으로 갑니다.
2. 아래쪽 **스크립트 속성** → **스크립트 속성 추가**.
3. 속성 `TEACHER_KEY`, 값에는 아무 비밀 문자열(예: `nakwon-2026-catch!`)을 넣고 저장합니다.
   이 값은 나중에 선생님 채점 페이지 설정에 넣습니다. 학생에게는 알려 주지 마세요.
4. (선택) `SUBMIT_CODE` 속성을 추가하면 학생이 제출할 때 그 코드를 입력해야 합니다. 아무나 올리는 것을 막고 싶을 때 쓰세요.

## 3. 웹 앱으로 배포

1. 오른쪽 위 **배포 > 새 배포**.
2. 왼쪽 ⚙️ 에서 유형 **웹 앱** 선택.
3. 설정:
   - 설명: `캐치볼 1`
   - **다음 사용자 인증 정보로 실행: 나**
   - **액세스 권한이 있는 사용자: 모든 사용자**  ← 학생이 로그인 없이 올리려면 꼭 "모든 사용자"
4. **배포** → 권한 확인 창이 뜨면 선생님 계정 선택 → "고급" → "캐치볼 평가(안전하지 않음)로 이동" → 허용.
   (선생님이 직접 만든 스크립트라서 뜨는 경고입니다.)
5. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.

## 4. 채점 페이지에 연결

1. 채점 페이지(`catchball.html`)를 열고 **설정 > 구글 드라이브·시트 연동**에
   - 앱스크립트 주소: 위에서 복사한 URL
   - 선생님 키: 2단계에서 정한 값
   을 넣고 **연결 확인**을 누릅니다.
2. 연결되면 **학생 제출 링크**가 만들어집니다. 이 링크를 학생들에게 보내면 됩니다. (링크 안에 앱스크립트 주소가 들어 있습니다.)

## 5. 어디에 저장되나

- 영상: 내 드라이브 > `캐치볼 제출` > `반 이름` > `날짜` > `학생1_학생2_시각.webm`
- 기록: 내 드라이브 > `캐치볼 평가 기록` 스프레드시트 (`제출목록`, `채점결과` 시트)
- 다른 폴더/시트를 쓰려면 스크립트 속성에 `ROOT_FOLDER_ID`, `SHEET_ID` 를 넣으면 됩니다.

## 코드를 고친 뒤에는

`Code.gs` 를 수정했으면 **배포 > 배포 관리 > ✏️ > 버전: 새 버전 > 배포** 를 해야 반영됩니다. URL 은 그대로 유지됩니다.

## 문제가 생기면

- "앱스크립트 응답을 읽을 수 없습니다": 배포 설정의 "액세스 권한"이 "모든 사용자"인지 확인하세요.
- "선생님 키가 맞지 않습니다": 스크립트 속성의 `TEACHER_KEY` 와 채점 페이지 설정값이 같은지 확인하세요.
- 학생 쪽에서 "드라이브에 직접 올리지 못했습니다"가 떠도, 영상이 40MB 이하면 자동으로 다른 방법(앱스크립트 중계)으로 올라갑니다. 제출 완료 화면이 나오면 성공입니다.
