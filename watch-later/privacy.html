"나중에 볼 영상"(이하 "서비스")은 이용자의 개인정보를 소중히 다루며, 「개인정보 보호법」 등 관련 법령을 지킵니다. 이 서비스는 무료로 운영되는 개인 프로젝트입니다.

1. 수집하는 개인정보와 목적

항목목적
구글 계정 이메일, 이름, 프로필 사진 (구글 로그인 시)회원 식별, 로그인
이용자가 저장한 영상 링크와 영상 정보(제목, 채널, 썸네일, 길이), 카테고리, 알림 시각, 별점·메모나중에 볼 영상 목록, 알림, 관심사 분석 기능 제공
알림 받을 기기의 푸시 알림 주소, 브라우저 정보정한 시간에 알림 보내기
주간 정리 알림 설정(요일·시각·시간대)주간 정리 알림 보내기

관심사 분석은 이용자의 기기 안에서만 계산되며, 분석 결과를 따로 저장하거나 외부로 보내지 않습니다.

2. 보관 기간과 파기

  • 회원 탈퇴 시 계정과 저장한 모든 정보를 즉시 삭제합니다. (앱 안 "회원 탈퇴" 버튼)
  • 영상이나 카테고리를 지우면 해당 정보는 바로 삭제됩니다.
  • 알림 받을 기기 정보는 로그아웃, 알림 끄기, 또는 기기에서 알림이 더 이상 유효하지 않을 때 삭제됩니다.

3. 제3자 제공

이용자의 개인정보를 다른 사람이나 회사에 팔거나 제공하지 않습니다. 광고에 사용하지 않습니다.

5. YouTube API 서비스 이용

이 서비스는 영상 제목·채널·길이 등을 가져오기 위해 YouTube API 서비스를 사용합니다. 이용자는 YouTube 서비스 약관과 Google 개인정보처리방침의 적용을 받습니다. 구글 계정 보안 설정 페이지(myaccount.google.com/permissions)에서 언제든 이 서비스의 접근 권한을 해제할 수 있습니다.

유튜브 좋아요 영상 가져오기

이용자가 "유튜브 좋아요 영상 가져오기"를 누르고 허용한 경우에만, 구글 권한 youtube.readonly(유튜브 계정 보기)를 사용해 좋아요 표시한 영상 목록(영상 ID, 제목, 채널, 썸네일, 길이, 분류)을 한 번 읽어 와 이용자의 "나중에 볼 영상" 목록에 저장합니다.

  • 유튜브 계정 접근 토큰은 서버에 저장하지 않으며, 가져오기가 끝나면 다시 사용하지 않습니다.
  • 유튜브 계정에 어떤 내용도 쓰거나 바꾸지 않습니다 (읽기 전용).
  • 가져온 정보는 이 서비스의 기능 제공에만 쓰며, 광고나 다른 목적으로 쓰거나 제3자에게 제공하지 않습니다.
  • 이 서비스가 Google API 로 받은 정보의 사용 및 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책(제한적 사용 요구사항 포함)을 따릅니다.
