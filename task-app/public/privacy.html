업무 챙김 개인정보처리방침

시행일: 2026년 10월 1일

업무 챙김(이하 “서비스”)은 「개인정보 보호법」 등 관련 법령을 지키며, 이용자의 개인정보를 아래와 같이 처리합니다.

학생 개인정보는 입력하지 마세요. 서비스는 교사 개인의 업무 관리용입니다. 업무 제목·메모·붙여넣는 공문에 학생 이름·연락처·성적·상담 내용 등 학생 개인정보를 적지 말아 주세요.

2. 보유 및 파기

  • 회원 탈퇴(설정 → 계정 → 회원 탈퇴) 시 계정과 모든 입력 내용을 즉시 영구 삭제합니다.
  • 장애 대비 백업 파일에는 최대 5주간 남아 있을 수 있으며, 이후 자동으로 삭제됩니다.
  • 1년 이상 로그인하지 않은 계정은 미리 알린 뒤 삭제할 수 있습니다.

3-1. AI 도움받기

서비스 서버는 AI 서비스에 어떤 내용도 보내지 않습니다.

  • 기본 방식: 앱이 만든 질문을 이용자가 직접 복사해, 이용자가 고른 AI 서비스(ChatGPT·Claude·Gemini 등)에 이용자 본인 계정으로 붙여넣습니다. 이때 AI 서비스로 전달되는 내용과 그 처리는 해당 AI 서비스의 약관·방침을 따릅니다.
  • 자기 API 키 방식(선택): 이용자가 설정에 자기 Anthropic API 키를 넣은 경우, 이용자 기기에서 Anthropic PBC(미국)로 질문이 직접 전송됩니다. 키와 내용은 서비스 서버를 거치지 않습니다.
  • 어느 방식이든 질문에 학생 개인정보나 비공개 내용이 들어가지 않도록 보내기 전에 지워 주세요.

4. 구글 사용자 데이터

업무 챙김이 Google API로부터 받은 정보를 사용하고 다른 앱으로 전송하는 것은 Google API 서비스 사용자 데이터 정책(제한적 사용 요구사항 포함)을 따릅니다. Gmail 내용은 이용자가 지정한 라벨의 메일에 한해 업무 초안을 만드는 데에만 쓰며, 사람이 읽지 않고, 광고나 AI 모델 학습에 쓰지 않으며, 서비스가 AI 서비스로 보내지 않습니다.

5. 이용자의 권리

  • 언제든 앱에서 자신의 정보를 보고 고치거나 지울 수 있고, 회원 탈퇴로 전부 삭제할 수 있습니다.
  • 구글 연동 권한은 구글 계정 → 서드파티 앱 액세스에서 언제든 해제할 수 있습니다.

6. 안전성 확보 조치

  • 모든 통신은 암호화(HTTPS)되며, 데이터베이스는 이용자 본인 데이터만 읽고 쓸 수 있도록 행 단위 접근 제어를 적용합니다.
  • 외부 서비스 키(구글 연동용)는 서버에만 보관하고 앱 화면에 노출하지 않습니다.
