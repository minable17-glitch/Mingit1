1AI와 대화하기 · 조건을 몰라도 돼요

상황만 말하면 AI가 아이디어를 펼쳐요. 그중 필요한 것만 고르고, 더 정할 게 있으면 질문받아요. 이 세 마디면 충분해요.

이미 만든 화면 코드가 있으면 그걸 붙여주고 시작해요. 화면은 그대로 두고 저장만 시트로 바꾸는 게 핵심이라, 대화가 훨씬 짧아요.

① 상황 말하기
구글 앱스크립트로 [무엇]을 만들려고 해. [상황·정원 등].
어떤 기능이나 입력 항목이 필요할까? 코드는 만들지 말고 아이디어만 알려줘.
① 코드 붙여주고 말하기
아래는 내가 만든 [무엇] 앱 코드야. 지금은 브라우저에만 저장돼서 다른 기기에서 열면 기록이 없어.
이걸 구글 앱스크립트로 옮겨서 시트에 저장되게 하려고 해. 화면은 그대로 두고 저장만 바꾸면 되는지, 더 정할 게 있는지 알려줘. 코드는 아직 만들지 마.

[기존 코드 붙여넣기]
② 고르기
[넣을 것]은 넣고, [뺄 것]은 빼고 싶어.
이대로 하면 실제로 쓸 때 생길 문제가 있을까?
② (원하면) 기능 더하기
옮기면서 [추가하고 싶은 것]도 넣고 싶어. 기존 기능은 그대로 유지해줘.
이대로 하면 생길 문제가 있을까?
③ 빈틈 질문받기
내가 더 정해야 할 게 있으면 한 번에 하나씩 질문해줘.
"코드는 만들지 마"가 핵심이에요. 이게 없으면 첫 마디에 코드가 쏟아져서 고를 기회가 없어요. 그리고 AI가 주는 걸 다 넣지 마세요 — 고르는 건 내 몫이에요.
2"정리해줘" · 꼭 들어갈 것과 함께

그냥 "정리해줘"만 하면 핵심이 빠진 채 정리될 수 있어요. 아래 세 가지를 같이 말해요. 채우면 마지막 말이 완성됩니다.

1
무엇을 만드는지 — "구글 앱스크립트로 ○○ 앱"'구글 앱스크립트'가 빠지면 시트와 상관없는 일반 웹앱이 돼요. 옮길 땐 "화면은 그대로, 저장만 시트로"가 자동으로 붙어요.
2
데이터 — 시트의 열 구조안 말하면 AI가 알아서 정해요. 원하면 직접 정할 수도 있어요.
3
처음이니 하나씩 — "코드 넣는 것부터 공유하는 것까지 하나씩 알려줘"이게 없으면 설명이 어려워서 못 따라가요.
마지막에 보낼 말

    
대화 중에 이미 말한 내용이라도 여기서 한 번 더 말해 두면 정리에서 빠지지 않아요.

  


  
  

    
3새 대화에 붙여넣기 · 코드 받기

    
AI가 정리해준 프롬프트를 복사해서 새 대화창에 붙여넣으면 코드와 따라 하기 설명이 나와요. 잘 되면 그걸로 끝이에요.

    
✓ 잘 되면 끝. 점검 안 해도 돼요.
