버그를 찾아 고치는 법 — 디버깅

코드를 만들다 보면 오류(버그)는 반드시 생깁니다. 중요한 건 그걸 침착하게 찾아 고치는 방법이에요. 아래 4단계를 눌러가며 익혀 보세요.

버그(bug) — 코드에 생긴 오류. 원하는 대로 동작하지 않는 부분.
디버깅(debugging) — 그 버그를 찾아서 고치는 과정.
🐛 1947년, 초창기 컴퓨터에 진짜 나방(bug)이 끼어 오작동한 일이 있었어요. 그걸 꺼내 고친 데서 "버그를 없앤다 = 디버깅"이라는 말이 유명해졌습니다.
버그는 실패가 아니에요. 프로 개발자도 하루의 상당 시간을 디버깅에 씁니다. 오류가 났다는 건 잘못한 게 아니라, 무언가를 만들고 있다는 증거예요. 당황하지 말고 하나씩 따라가면 됩니다.

디버깅 4단계

AI에게 버그를 잘 넘기는 법

❌ 막연한 요청
"안 돼요."
"이거 좀 고쳐줘."
✅ 좋은 요청
"이름을 눌러도 별 숫자가 0 그대로야. 별을 더하는 부분을 찾아서 고쳐줘. 어디를 바꿨는지도 알려줘."
좋은 요청에는 세 가지가 들어갑니다.
  1. 증상을 구체적으로 — "안 돼요"가 아니라 "눌러도 숫자가 0 그대로야"
  2. 짐작되는 위치 — "별을 더하는 부분", "색이 투명한 것 같아"
  3. 고친 곳을 설명해달라 — 다음엔 스스로 찾을 수 있도록

이제 직접 해볼 차례예요

코드 고치기 실습판에서 버그를 찾아 고쳐 보세요. 제대로 고치면 "성공!" 표시가 뜹니다. 4단계를 그대로 따라가 보면 됩니다.
